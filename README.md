# Turnview 本地网页旋转台

一个无需安装依赖的本地网页工具，可以把网页旋转到任意角度，适合竖屏显示器、平板、展示屏或需要暂时改变阅读方向的场景。

## 打开方式

直接双击 `启动网站.cmd`，浏览器会自动打开；也可以双击 `index.html`，用 Edge、Chrome 或其他现代浏览器打开。

如果希望手动启动本地服务，可以在本目录打开 PowerShell 并运行：

```powershell
python -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 使用

1. 输入网页地址并点击“载入网页”。
2. 使用 0°、90°、180°、270° 快捷按钮，或拖动精细旋钮。
3. 可以缩放、水平/垂直翻转、开启“移动视图”来拖动画面。
4. 点击“本地 HTML”载入本机 `.html` 或 `.htm` 文件，也可以直接把文件拖进预览区。
5. 按 `R` 顺转 90°，`Shift + R` 逆转 90°，`0` 归零，`H` 切换移动模式，`F` 全屏。

## 注意事项

- 部分网站（例如 Google、部分视频站和银行网站）会通过安全策略禁止被其他页面嵌入。这是网站自身的限制，旋转工具不会绕过它；遇到这种情况可点击“新窗口打开”，但新窗口中的页面无法由本工具旋转。
- 载入的网页运行在独立预览框中，本工具不会读取或修改网页内容。最近网址仅保存在当前浏览器的本地存储中。
- 本地 HTML 中的相对路径资源（图片、CSS、脚本）可能无法载入；自包含 HTML 的显示效果最好。
